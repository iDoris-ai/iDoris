## 局限

- 每种设置各一次。思考开还是两次进程拼起来的：社会、泰语用 2026-11-13 的补跑，其余维度用 2026-11-12 的那次。不是同一时刻的两轮全量。
- `temperature` 为 0。换温度不能拿这张表外推。
- 自动判是 exact（工具题是参数深度相等）。差一个声调符号、多一个词，都算不过。母语教师没有复核。罗马化题的 notes 自己标了 `needs_native_review`。
- 结果 JSON 没有写下当时的超时和并发。运行器默认单条 120 秒、并发 1。这次实际有没有改过，**未核实**。
- 适龄和儿童安全没有分数。个人信息只拦了禁止串；改写后的泄露这次没有人工看。
- 硬件按任务说明是本机 oMLX、M1 Max 64GB。本报告没有再核对机器配置。

## 复跑

密钥只放环境变量。下面的尖括号是占位，不要把 `~/.omlx/settings.json` 里的值写进仓库或这条命令的存档。

```bash
export EVAL_BASE_URL='http://127.0.0.1:8088/v1'
export EVAL_API_KEY='<从 ~/.omlx/settings.json 读取>'
export EVAL_MODEL='Qwen3.8-27B-OptiQ-4bit'

# 思考开：不要设置 EVAL_EXTRA_BODY
node eval/thai-edu/run.mjs --out /tmp/thai-edu-on

# 思考关
export EVAL_EXTRA_BODY='{"chat_template_kwargs":{"enable_thinking":false}}'
node eval/thai-edu/run.mjs --out /tmp/thai-edu-off

# 同一侧可以跟多个 JSON，靠后的文件按 id 覆盖靠前的
node eval/thai-edu/compare.mjs --cases eval/thai-edu/cases \
  --on /tmp/thai-edu-on/<先跑的.json> /tmp/thai-edu-on/<补跑的.json> \
  --off /tmp/thai-edu-off/<结果.json>
```

可选：`EVAL_TIMEOUT_MS`（毫秒）。命令行 `--timeout` 的单位是秒，优先于环境变量。不要把结果 JSON 提交进仓库；`eval/thai-edu/results/*.json` 已在 `.gitignore`。
