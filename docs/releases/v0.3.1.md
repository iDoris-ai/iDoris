## 主要变化

- **角色绑定真实模型**：HTTP 组件卡可用 `extensions.idoris_role_models` 把角色映射到后端实际安装的模型 ID，选模与加载、转发使用同一确切 ID（[#510](https://github.com/iDoris-ai/iDoris/pull/510)；说明见 `config/role-model-bindings.md`）。
- **内存额度：推荐与运行时准入**：`IDORIS_ALLOCATED_BUDGET_BYTES` 以整数字节同时约束推荐/能力报告与生命周期加载准入（[#511](https://github.com/iDoris-ai/iDoris/pull/511)、[#512](https://github.com/iDoris-ai/iDoris/pull/512)；验收 [#514](https://github.com/iDoris-ai/iDoris/pull/514)、[#523](https://github.com/iDoris-ai/iDoris/pull/523)）。
- **闸一隐私检查（inspect / kill switch / breakers）**：请求 inspect（编码内容、规避归一化、凭证与证件号检测、跨行 ID 等）、远程 kill switch（[#432](https://github.com/iDoris-ai/iDoris/pull/432)）、离机出站字节统计（[#530](https://github.com/iDoris-ai/iDoris/pull/530)）；provider 熔断器（[#438](https://github.com/iDoris-ai/iDoris/pull/438)、[#439](https://github.com/iDoris-ai/iDoris/pull/439)）及后续 breaker 声明/票据修复（[#538](https://github.com/iDoris-ai/iDoris/pull/538)、[#539](https://github.com/iDoris-ai/iDoris/pull/539)、[#543](https://github.com/iDoris-ai/iDoris/pull/543)、[#544](https://github.com/iDoris-ai/iDoris/pull/544)）；inspect 前缀重放 [#529](https://github.com/iDoris-ai/iDoris/pull/529)；协议事件与决策链记录 [#556](https://github.com/iDoris-ai/iDoris/pull/556)、[#558](https://github.com/iDoris-ai/iDoris/pull/558)、[#559](https://github.com/iDoris-ai/iDoris/pull/559)；内容收紧在路由决策中记录 [#572](https://github.com/iDoris-ai/iDoris/pull/572)、[#575](https://github.com/iDoris-ai/iDoris/pull/575)、[#576](https://github.com/iDoris-ai/iDoris/pull/576)。
- **付费预算与并发**：预算并发验收 [#436](https://github.com/iDoris-ai/iDoris/pull/436)；调度日志中止时释放付费预留 [#552](https://github.com/iDoris-ai/iDoris/pull/552)；付费预留与完成上限移植到 v0.3.1 main [#573](https://github.com/iDoris-ai/iDoris/pull/573)。
- **原生载荷与生成截止**：原生模型载荷、响应身份与生成截止修复 [#521](https://github.com/iDoris-ai/iDoris/pull/521)；本地生成独立 120 秒截止 [#526](https://github.com/iDoris-ai/iDoris/pull/526)。
- **release / onboarding 工具**：独立 CLI 签名公证与 DMG 验证工具 [#522](https://github.com/iDoris-ai/iDoris/pull/522)、签名发行验收与无资产 draft 流程 [#525](https://github.com/iDoris-ai/iDoris/pull/525)、已有 tag 检查的 SIGPIPE 修复 [#527](https://github.com/iDoris-ai/iDoris/pull/527)、发布后 onboarding 与隔离 smoke [#507](https://github.com/iDoris-ai/iDoris/pull/507)。
- **依赖安全**：`tokio` 升至 1.53.3，修复 RUSTSEC-2026-0386（[#580](https://github.com/iDoris-ai/iDoris/pull/580)）；此前 `rustls` advisory 修复（[#545](https://github.com/iDoris-ai/iDoris/pull/545)）。
- **推荐器：放不下时给用户两个选项**（owner 2026-10-27 决定，[#579](https://github.com/iDoris-ai/iDoris/pull/579)）：最优临时模型放不下时，`TempChoice` 本身是「清理后加载最优」，`degraded_alternative` 是「不清理、降级到现在就放得下的同能力模型」。分配额度模式下，超出总额的最优模型在 `BlockedChoice.degraded_alternatives` 按能力给出备选。`headroom_breach_option` 是只有用户逐次确认后才可占用 1GB 余量的更优常驻选项，绝不自动生效。三者都只在库层提供，`/capabilities` 的 HTTP 形状不变。
- **闸一漏检修复**：字面 `\u` 后跟 1–3 位数字、紧贴身份证号时不再漏检（[#578](https://github.com/iDoris-ai/iDoris/pull/578)，关闭 [#534](https://github.com/iDoris-ai/iDoris/issues/534)）。
- 其他：tenant 授权上限与事件写入前校验修复 [#508](https://github.com/iDoris-ai/iDoris/pull/508)。

## 已知限制

- Supervisor/生命周期路径拒绝不支持的采样字段，包括 `temperature`（HTTP 400，`unsupported_field` / `unsupported_parameter`）；允许 `model`、`messages`、`stream`、`max_tokens`（>0）、`tools`、`response_format`、`tool_choice`、`parallel_tool_calls`、`chat_template_kwargs`、`disable_thinking`。
- 没有 launcher；不自动安装引擎或模型权重。
- 内存额度不限制外部 resident 服务或实际 RSS，无动态预算 API，修改需重启。
- 推荐器的降级备选和余量突破选项还没有经 HTTP 暴露；暴露方式下一期与 Agent24 商定。
